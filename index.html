Desk Wick

A touchscreen market terminal and macropad that sits on your desk. Flash it, plug in a screen, and it boots straight into the UI.

.img.xz for Raspberry Pi Imager · 64-bit · built on Raspberry Pi OS (Trixie)

  • Raspberry Pi 4 or 5
  • 800×480 or 1024×600 touchscreen
  • 8GB+ card

What it does

Everything on screen is a tile in a grid you lay out yourself. A tile is a live quote or a macro button — swipe between pages of them.

Flash it

Takes about five minutes. You don't need to unzip the download — Imager reads .img.xz directly.

  1. Open Raspberry Pi Imager and choose your Pi model and SD card.

    Under Operating System, scroll to the bottom and pick Use custom, then select the downloaded deskwick.img.xz.

  2. Fill in Imager's customisation dialog.

    Set a username and password, your WiFi, and enable SSH. This is the important step — none of that is baked into the image, so the Pi has no way onto your network without it.

  3. Write, then boot the Pi with the screen attached.

    First boot takes a couple of minutes while it expands the filesystem and configures itself. It reboots once, then comes up in the terminal — no desktop, no cursor, no browser chrome.

Out of the box it runs on simulated market data, so you can confirm everything works before setting up an API key.

Set it up

Both of these are done from another machine — the Pi's IP or hostname on port 8080.

Lay out your tiles

Open http://<pi>:8080/editor in a normal browser. Drag tiles, set symbols, bind macro keystrokes. Changes appear on the device immediately.

Add live prices

Put a free Finnhub key in /opt/deskwick/backend/.env and restart, and the simulated data is replaced with real quotes. 

ssh <user>@<pi>
sudo nano /opt/deskwick/backend/.env     # FINNHUB_API_KEY=...
sudo systemctl restart deskwick

Driving your computer

Macro buttons send keystrokes to the machine you actually work on. Two ways, and you can use both at once — it's set per button.

Over USB

The Pi presents itself as a real USB keyboard, so there's nothing to install on the other machine. Cable its USB-C port to your computer and power the Pi from the GPIO pins instead.

Over the network

Run the small companion agent on the target machine and point the Pi at it. No cables, and it can drive more than one computer.

Built for personal use. Market data comes from free API tiers, which are licensed for personal, non-commercial use.
